# OAK-D S2 도입 전 준비 가이드

대표님, 하드웨어가 도착하기 전에 미리 준비해 두면 프로젝트를 한 달 이상 단축할 수 있는 핵심 액션 가이드입니다.

---

## 1. 데이터 수집: 모델의 '밑거름' 만들기
OAK-D S2가 최고의 눈을 가졌더라도, 학습 데이터가 부족하면 누락을 잡기 어렵습니다. 

- **촬영 대상**:
  - 정상 패키징 (유부 + 후리가케 + 참기름 모두 포함)
  - 구성품별 누락 상황 (참기름만 빠진 경우, 후리가케만 빠진 경우 등)
- **촬영 방법**:
  - 스마트폰으로 **실제 라인과 비슷한 높이와 각도**에서 촬영하십시오.
  - 조명이 너무 어둡거나 반사가 심하지 않도록 주의하십시오. (식품 패키지는 비닐 반사가 많으니 LED 조명을 옆에서 비춰주는 게 좋습니다.)
- **수량**: 클래스당 최소 **50~100장**의 이미지가 있으면 초기 테스트에 충분합니다.

## 2. 데이터 라벨링 (Labeling)
수집된 이미지 속 물체가 무엇인지 AI에게 가르쳐주는 단계입니다.

- **추천 도구**: [Roboflow](https://roboflow.com/)
  - **왜?**: OAK-D S2 제작사인 Luxonis와 연동이 가장 잘 되며, 클릭 몇 번으로 데이터 증강과 내보내기가 가능합니다.
- **방법**: 
  - `tofu_skin` (유부)
  - `furikake` (후리가케)
  - `sesame_oil` (참기름)
  - 위 3가지에 대해 꼼꼼하게 바운딩 박스를 그려주십시오.

## 3. 개발 PC 환경 설정
미리 라이브러리를 설치해 두면 장비 도착 즉시 꽂아서 테스트할 수 있습니다.

- **필수 설치**:
  1. **Python 3.9 ~ 3.11** (호환성이 가장 좋습니다.)
  2. **DepthAI SDK**: OAK-D를 구동하는 핵심 엔진입니다.
- **설치 명령어**:
  ```bash
  pip install opencv-python depthai
  ```

## 4. 대표님을 위한 코다리 팁 😎
- **샘플 확보**: 참기름 패키지가 유독 작다면, 카메라 줌 기능보다는 **카메라를 물리적으로 조금 더 가깝게 설치**할 수 있도록 브라켓 위치를 미리 생각해보시는 게 좋습니다.
- **공간 확보**: OAK-D S2는 USB-C 케이블을 사용합니다. 라인에서 PC까지의 거리를 확인하시고, 필요한 경우 **'Active USB Extension Cable'**을 미리 주문해 두십시오. (일반 케이블은 길어지면 인식이 안 됩니다!)
