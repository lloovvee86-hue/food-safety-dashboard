# OAK-D S2 원격 개발 및 현장 적용 가이드

대표님, 회사 노트북에서 개발하고 멀리 떨어진 현장 카메라에 적용하는 것은 충분히 가능합니다! 가장 현실적이고 효율적인 3가지 아키텍처를 제안해 드립니다.

---

## 1. 전용 엣지 PC 활용 (Host-Target 방식) - **[가장 일반적인 방식]**
현장에 OAK-D S2를 연결할 작은 PC(미니 PC 또는 산업용 PC)를 하나 두는 방식입니다.

- **구성**: [노트북] --(인터넷/VPN)-- [현장 PC] --(USB)-- [OAK-D S2]
- **방법**: 
  1. 노트북에서 코드를 짭니다.
  2. **GitHub**나 **공유 폴더**를 통해 현장 PC로 코드를 보냅니다.
  3. **SSH** 또는 **AnyDesk(원격 데스크톱)**로 현장 PC에 접속해 스크립트를 실행합니다.
- **장점**: 인터넷이 잠시 끊겨도 현장 PC가 계속 돌아가므로 시스템이 안정적입니다.

## 2. PoE 카메라 활용 (Network 방식) - **[장비 변경 가능 시 추천]**
만약 아직 구매 전이라면, USB 모델 대신 **OAK-D S2 PoE** 모델을 선택하는 방법입니다.

- **구성**: [노트북] --(네트워크/VPN)-- [OAK-D S2 PoE (자체 IP 보유)]
- **방법**: 
  1. 카메라를 공장 네트워크망에 연결합니다.
  2. 노트북에서 스크립트를 실행할 때 카메라의 **IP 주소**만 입력하면 멀리서도 즉시 카메라 화면을 가져오고 모델을 적용할 수 있습니다.
- **장점**: 별도의 현장 PC가 필요 없으며, 전원과 데이터 전송을 랜선 하나로 끝낼 수 있습니다.

## 3. RobotHub 활용 (Cloud 방식) - **[관리형 서비스]**
Luxonis에서 제공하는 **[RobotHub](https://robothub.luxonis.com/)** 플랫폼을 사용하는 방식입니다.

- **구성**: [노트북] --(웹 브라우저)-- [RobotHub 서버] -- [현장 카메라]
- **방법**: 
  1. 웹 브라우저에서 카메라 상태를 모니터링합니다.
  2. 새로 만든 AI 모델 파일을 웹사이트에 업로드하고 '배포' 버튼만 누르면 전 세계 어디든 있는 카메라에 즉시 적용됩니다.
- **장점**: 서버 관리나 네트워크 설정 없이 가장 세련되게 관리할 수 있습니다.

대표님, 현재 상황에서 가장 추천드리는 단계는 다음과 같습니다.

1. **개발 단계**: 지금처럼 노트북에서 데이터를 학습시키고 테스트 모델을 만듭니다.
2. **현장 설치**: 현장에 저렴한 **미니 PC**를 하나 마련하시고, 여기에 OAK-D S2를 꽂습니다.
